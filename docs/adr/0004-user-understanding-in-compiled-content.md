# Personal understanding can be merged into compiled content

The library represents the user's understanding. Comments remain in Source Annotation, while personal understanding explicitly submitted for preservation can also be merged directly into Draft without a user-judgment label. Compiler need not classify original text and Annotation into separate fact or judgment categories.

Integrated content retains Source links for verification. Suspected errors in the user's understanding are AI supplementary information, leaving the decision to Review rather than replacing it with attribution classification or silent correction.
