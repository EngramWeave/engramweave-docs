# Review Vault-local candidates against current files

Store temporary ChangeSets in Vault-root `70_ChangeSets/<id>/` with a manifest and candidate files mirroring formal target paths, excluded from Git and normal registration/recall; keep approved-execution recovery receipts in Core application data. Review in Obsidian with CodeMirror 6 MergeView, read-only Current on the left and editable Candidate on the right, so saving edits never applies formal changes and refreshing Current preserves Candidate; retain native Draft editing and avoid a second editable Desktop review surface. The first version uses no persistent Base directory or automatic three-way merge, trading automatic reconciliation for explicit human composition while retaining execution preconditions, temporary recovery safeguards, and cleanup after successful consumption or explicit cancellation.
