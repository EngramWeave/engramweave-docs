# Review and planning remain under explicit user control

Review Complete permits planning without binding to an exact Draft version; later edits neither revoke review nor invalidate candidates automatically. Each planning round reads current Draft and local library content at startup, while users review proposed files against current local files and form the final approved contents before Core applies them.

This preserves ordinary note editing and makes cancellation or replanning explicit, instead of introducing real-time Draft monitoring and automatic approval invalidation. An unapproved ChangeSet never changes formal files; approved execution checks target preconditions and proceeds independently of later Draft edits.
