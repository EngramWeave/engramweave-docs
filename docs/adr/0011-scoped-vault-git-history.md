# Git tracks selected user assets and commits integration files only

Track Ideas, Knowledge, Research, Projects, selected user System configuration, and Source Record Markdown files, excluding independent Assets, derived data, Drafts, and Inbox to limit repository growth. After successful approved integration, Core commits only its involved tracked files in their final approved state, including any earlier uncommitted user edits in those files; unrelated changes remain outside that commit.

Planning and candidate review use current local files rather than the latest Git commit. Users can separately commit edits manually or on a schedule; Git history does not introduce a pre-integration snapshot requirement or another approval gate.
