# Multiple Drafts may belong to an unarchived Source

An unarchived Source may have multiple Drafts, including results of later compilation, while preserving earlier Drafts and user edits. Only one Draft is selected for final integration; after that integration succeeds and the Source is archived, all related Drafts are marked discarded. This clarifies the earlier single-work-line wording in ADR-0002: it does not prohibit multiple editable Drafts before archival, and multiple retained Drafts do not authorize integrating several candidates from the same submission.
