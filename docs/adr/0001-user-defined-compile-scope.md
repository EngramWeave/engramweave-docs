# Users define compilation scope through submission

Compiler denoises and lightly refines material users have already judged valuable and explicitly submitted. Paper full text and existing notes can support understanding but do not become additional compilation targets merely by being included as context. Compiler does not independently discover more paper knowledge or add unsolicited explanations.

This keeps valuable content selection in the user's submission rather than expanding review through whole-paper summarization. One submission produces one Draft. Integration Planner proposes final splitting, merging, and placement; analysis and risk suggestions remain Review Metadata.
