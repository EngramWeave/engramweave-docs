# Source identity and archival follow each submission

Each explicit submission forms an independent Source with shared original references and its own locations. Multiple Sources may refer to the same Zotero paper. Archival means successful integration of final content compiled and reviewed from that submission, not completion of the whole paper.

Source primarily refers to the Source Record with Properties. It has one Draft work line with recoverable revisions and one final reviewed candidate, not parallel candidates. Planner may integrate that candidate into multiple formal knowledge files sharing the Source Record reference.

One workflow Source for an entire paper would let the first archived selection affect later selections' eligibility and conflate their comments and processing states. Paper references provide shared provenance; submitted Sources provide separate workflow identities. Delivery retry deduplication remains a separate behavior contract.
