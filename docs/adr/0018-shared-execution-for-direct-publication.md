# Direct publication shares approved execution and Git

After P3, retain the human-approved Publish to Knowledge shortcut for creating a new note without requiring Integration Planner or another approval step, while routing it through the same deterministic execution, archival/recovery and scoped Git commits as approved ChangeSets. This preserves the lightweight interaction without maintaining two independent formal-write and history policies; the P2 MVP's deferred Git behavior remains current until this extension is implemented.

Preserve recovery of already accepted P2 publication receipts during the transition. Full knowledge reorganization still uses Planner and ChangeSet review; keeping a shortcut does not allow direct overwrite of existing notes or authorize AI changes without approval.
